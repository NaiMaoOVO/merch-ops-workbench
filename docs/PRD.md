# 海外商品运营工作台 PRD

**版本**：v0.1
**日期**：2026-08-22
**状态**：需求基线，待入职后用真实样表校准
**产品形态**：个人、本地优先的桌面浏览器工作台
**目标用户**：一名希音商品运营实习生及其指定的一位朋友

## 1. 产品摘要

海外商品运营工作台是一款运行在本地浏览器中的个人运营辅助工具，帮助新人完成商品数据分析、策略诊断、标题优化、市场热点记录、供应商问题跟进、日常任务和周报整理。

工作台不连接希音内部系统，不直接修改线上商品，不要求登录，也不把真实业务数据默认上传到云端。用户可以导入 Excel/CSV，完成多表匹配、数据质量检查、透视分析、异常识别和报告导出；AI 只作为可选辅助，用于解释异常、提出原因假设、生成标题候选和整理汇报文字，所有结果都由用户人工确认。

首个核心工作流是：

```text
导入数据 -> 字段识别 -> 多表匹配 -> 数据质量检查 -> 指标分析
-> 异常识别 -> AI 辅助原因假设 -> 人工确认策略 -> 报告导出
```

## 2. Capability

### 2.1 能力陈述

让一名刚开始接触 VLOOKUP 和数据透视表的商品运营新人，在不了解真实业务字段的情况下，也能用本地工具完成一次可解释、可复盘、可导出的商品经营分析，并逐步沉淀可复用的字段模板、分析规则、标题规则和周报模板。

### 2.2 固定决策

- 个人本地优先，不做账号、团队权限和在线协作。
- 每个人拥有独立的本地数据，只共享模板、示例数据和教程。
- 首版使用 Chrome/Edge 浏览器桌面端运行。
- 不直接连接 SHEIN 内部系统，不自动修改线上商品。
- 不绑定单一 AI 模型，采用兼容接口配置。
- 本地规则分析不依赖 AI；AI 不可用时基础功能仍可用。
- 原始文件只读，所有清洗和分析生成本地处理副本。
- AI 默认脱敏，发送前预览，用户手动放行。
- 分析结论必须能够查看数据来源和计算口径。
- AI 的原因只能标记为“辅助假设”，不得自动写成确定事实。
- 所有批量标题必须人工审核后才可导出。
- 首版办公软件中立，不直接连接飞书，提供适合飞书等工具的复制和导出格式。

### 2.3 非目标

- 不做在线多人协作、账号体系、权限管理和云端数据库。
- 不做 SHEIN 后台自动操作、自动上架、自动修改标题或自动发布策略。
- 不做默认的外部平台爬虫，不绕过登录、验证码或访问限制。
- 不把 AI 当作指标计算、数据清洗或最终决策引擎。
- 不在 MVP 中实现完整 Word 排版软件、实时协同编辑或复杂审批流。
- 不在首版承诺任何未经确认的 SHEIN 专属字段、指标口径或平台规则。

## 4. 用户场景

### 4.1 每周商品数据分析

用户创建“2026 年第 N 周商品经营分析”，导入销售、流量、商品、库存和供应商等文件，系统推荐字段关系；用户逐步确认匹配，查看数据质量报告，运行分析规则，处理异常商品，并生成一份可汇报的周报。

### 4.2 商品标题维护

用户导入待维护商品，补充商品事实和目标语言，系统生成 1～3 个候选标题，检查长度、关键词、敏感词和事实一致性；用户逐条审核后导出已确认结果。

### 4.3 供应商问题跟进

用户快速记录供应商问题，关联商品和截图，设置优先级、负责人和截止时间，在首页查看逾期和待处理事项，关闭问题时填写解决方案。

### 4.4 热点观察

用户手动记录热点，或导入热点 Excel/CSV，填写来源链接和截图，关联品类、商品和标题任务；AI 可将观察整理为趋势假设，但不自动代表市场事实。

### 4.5 新人练习

用户使用内置模拟数据完成分级练习，学习 VLOOKUP/XLOOKUP、透视表、指标计算和异常诊断，然后替换为真实表格。

## 8. 核心工作流：商品数据分析与策略诊断

### 8.1 新建项目

项目字段：

- 项目名称
- 分析周期
- 站点
- 品类范围
- 数据来源备注
- 使用的字段模板
- 使用的分析规则模板
- 使用的报告模板
- 项目状态：未开始、进行中、待确认、已完成、已归档

支持复制上周项目，复制内容包括字段映射、匹配链路、过滤器、规则阈值、图表选择和报告结构，但不覆盖原项目。

### 8.2 导入数据

支持：

- `.xlsx`，支持多个工作表
- `.xls`
- `.csv`
- 一次导入多个文件
- 单个文件默认建议不超过 50MB，具体限制可配置
- 后续预留 `.tsv`、`.json` 和其他运营系统导出格式

导入预览：

- 文件名、工作表名、行列数
- 自动识别表头行、空行和编码
- 预览前 20～50 行
- 识别日期、数值、文本和空值
- 标记疑似主表、明细表和映射表
- 不修改原始文件

### 8.3 字段识别与映射

- 系统根据表头名称、数据类型和样例值推荐业务字段。
- 字段分为必选、推荐和可选。
- 真实字段未知时，不阻断导入；缺少字段只关闭依赖该字段的分析。
- 用户可手动修改映射并保存模板。
- 模板按项目、品类、站点或来源文件类型保存。
- 映射建议展示置信度和推荐理由。

推荐的初始字段类别：

| 类别 | 示例字段 | 默认级别 |
|---|---|---|
| 商品信息 | 商品 ID、商品名称、品类、供应商、站点、上架时间 | 推荐 |
| 流量指标 | 曝光、访问、点击、点击率 | 推荐 |
| 交易指标 | 加购、下单、支付件数、销售额、转化率 | 推荐 |
| 商品状态 | 库存、价格、折扣、上下架状态 | 可选 |
| 时间字段 | 日期、周次、统计周期 | 推荐 |

以上不是 SHEIN 固定字段，拿到真实样表后应通过模板和字段别名扩展。

### 8.4 多表匹配

- 支持任意合理数量的表，首版建议单个任务最多 10 张，避免浏览器性能下降。
- 用户指定一张主表，其余为补充表。
- 支持连续匹配，例如销售表 → 商品表 → 供应商表 → 品类表。
- 系统推荐匹配键，例如商品 ID ↔ 商品编码。
- 用户逐步确认每个匹配关系。
- 支持保留列选择、字段冲突处理和列重命名。
- 匹配前后均提供预览。

必须检查：

- 匹配成功数量
- 未匹配数量和示例
- 空键
- 重复键
- 一对多和多对多关系
- 字段类型冲突
- 同名字段冲突
- 连接后行数异常增长

每个匹配步骤保存：来源表、目标表、匹配键、匹配方式、保留字段、异常数和确认时间。

学习模式同时显示等价的 VLOOKUP/XLOOKUP 和 Power Query 操作说明。

### 8.5 数据质量检查

导入或匹配完成后生成数据质量报告：

- 表头和字段完整性
- 空值率
- 重复键
- 日期范围异常
- 数值字段包含文本
- 负数或极端值
- 关联失败
- 指标分母为零
- 同一商品多周期重复
- 可能的单位不一致

用户可以选择修复方式：忽略、填充、删除、转换类型或返回源文件处理。原始数据永不被覆盖。

### 8.6 分析与透视

默认分析维度：品类、供应商、站点、时间、商品。

默认指标：销售额、支付件数、曝光、点击率、加购率、转化率、在售商品数、异常商品数。所有指标均需显示数据周期和计算口径。

支持：

- 筛选、排序和分组
- 维度切换
- 指标新增、隐藏和排序
- 环比和同比（缺少对比周期时不显示）
- 明细下钻
- 透视结果保存为分析视图
- 复制视图到其他项目

### 8.7 异常规则

内置规则：

- 高曝光低点击
- 高点击低转化
- 销售额下滑
- 库存不足
- 库存积压
- 品类表现低于整体平均
- 供应商表现异常
- 新品无流量或无成交

每条规则可配置：时间范围、品类、站点、对比周期、百分比阈值、绝对数值阈值和是否启用。

规则模板支持新增、复制、编辑、停用、导入和导出。

异常结果必须包含：触发规则、阈值、实际值、对比基准、数据周期和证据行。

### 8.8 图表

首版支持：

- 趋势折线图
- 品类、供应商、站点对比柱状图
- 曝光到支付的漏斗图
- 曝光与转化率散点图
- TOP 和低表现商品条形图
- 库存状态分布图
- 环比变化表

图表要求：可点击下钻、显示口径和周期、缺少字段自动隐藏、可在报告中选择显示，不使用 3D 或纯装饰图。

### 8.9 策略诊断卡片

统一结构：

1. 发现：哪个指标或商品异常
2. 证据：数据、时间范围、对比基准
3. 可能原因：规则或 AI 提出的待验证假设
4. 建议动作：可执行的下一步
5. 优先级：高、中、低
6. 负责人和截止日期
7. 处理状态：待确认、已采纳、处理中、已完成、已忽略
8. 处理结果：执行后指标是否改善
9. 人工备注

AI 只能生成“可能原因”和“建议表达”，必须显示辅助标记。用户确认后，才进入正式策略记录或报告。

## 9. 标题优化

### 9.1 输入

- 原标题
- 商品 ID
- 品类
- 属性
- 材质、颜色、尺寸和功能
- 核心卖点
- 目标关键词
- 目标站点
- 目标语言
- 字符限制
- 禁用词、品牌词和合规要求

### 9.2 生成与审核

- 支持批量导入和批量生成。
- 每个商品生成 1～3 个候选标题。
- 中文、英文及后续语言分别生成和校验，共享同一份商品事实。
- 展示原标题、新标题、修改差异、使用的卖点、关键词和 AI 理由。
- 支持逐条编辑、选择、退回、待定和批量确认。
- 只有人工确认的标题才能导出。
- 不自动写回任何线上系统。

### 9.3 规则模板

默认检查：

- 长度或字符数
- 空标题和重复标题
- 敏感词、禁用词
- 品牌词使用
- 关键词堆砌
- 缺少核心属性
- 特殊符号过多
- 多语言混用异常
- 与商品事实不一致

规则按语言、站点和品类维护，支持自定义禁用词、必备属性、字符上下限和关键词重复次数。

结果必须区分：

- 平台明确禁止
- 工作台建议优化
- 需要人工确认

## 10. 热点与选品观察

### 10.1 首版输入

- 手动记录
- Excel/CSV 导入
- 来源链接
- 截图或附件备注

热点字段：关键词、品类、来源平台、来源链接、发现日期、热度判断、相关商品、相关卖点、观察结论、后续动作、状态。

### 10.2 AI 辅助

AI 可将多条观察整理为趋势摘要、候选卖点和待验证方向，但必须显示来源和不确定性，不将 AI 摘要当作外部平台事实。

### 10.3 外部数据接口预留

首版不启用自动爬取，但预留连接器接口：

- 数据源配置
- 授权或登录状态
- 请求频率限制
- 字段标准化
- 热点去重
- 来源可信度
- 失败重试
- 人工导入回退
- 合规和隐私开关

不得通过接口绕过访问限制、验证码或未授权数据边界。

## 11. 供应商问题台账

默认字段：

- 供应商名称或编码
- 问题标题
- 问题类型
- 关联商品
- 问题描述
- 来源：聊天、邮件、表格或其他
- 优先级
- 当前状态：待确认、处理中、等待供应商、已解决、已关闭
- 负责人
- 截止日期
- 处理记录
- 截图或附件
- 最终解决方案
- 是否需要复盘

支持自定义字段、状态、优先级和问题类型。

支持按供应商、状态、优先级、截止日期和关联商品筛选；首页展示临期和逾期问题。关闭问题时要求填写解决方案或备注。

## 12. 日常任务

任务字段：标题、描述、来源、优先级、负责人、截止日期、关联项目或商品、状态、处理记录、附件。

状态：待处理、进行中、等待他人、已完成、已取消。

任务来源可以是手动创建、分析结果、标题任务、供应商问题或报告待办。AI 只能帮助整理，不自动关闭或改期。

### 13.1 报告模块

- 报告标题和周期
- 核心指标卡片
- 趋势图表
- 异常商品表
- 策略诊断卡片
- 标题优化结果
- 供应商问题
- 日常完成事项
- 待跟进事项
- 需要上级支持的问题
- 备注和结论

### 13.2 编辑能力

- 修改文字
- 拖动模块顺序
- 显示或隐藏模块
- 选择图表
- 编辑表格内容
- 修改标题、周期和署名
- 恢复 AI 原始建议
- 保存为报告模板

保留后续扩展：自由排版、页眉页脚、分页控制、批注、现有 Word 模板导入和在线编辑。

### 13.3 导出

- Excel：明细、异常商品、透视结果、标题建议
- Markdown/HTML：适合复制到飞书、企业微信、Notion、邮件或普通文档
- Word：正式周报和汇报材料
- PDF：固定版式归档和发送

导出前运行完整性检查，标记未确认的 AI 建议、缺少字段和异常数据。导出的报告应包含数据周期、规则版本和生成时间。

## 16. AI 能力与安全

### 16.1 配置

- DeepSeek、OpenAI 等预设
- 兼容 OpenAI API 格式的自定义接口
- 自定义接口地址、模型名称和 API Key
- 测试连接
- API Key 仅本地保存，不进入导出和备份

### 16.2 可用场景

- 异常指标的原因假设
- 策略建议表达
- 多语言标题候选
- 热点摘要
- 周报文字整理
- 教程和错误说明的个性化解释

### 16.3 数据发送规则

- 默认不发送完整原始表格。
- 只发送用户选中的行、汇总指标和必要字段。
- 商品 ID、供应商名称和内部编码默认匿名化。
- 用户可配置脱敏字段。
- 发送前显示预览、字段列表和目标接口。
- 用户可以取消发送。
- API 调用记录默认只保存摘要，不保存完整敏感请求。
- AI 返回内容标记“辅助建议”。

## 17. 数据、生命周期与恢复

### 17.1 核心实体

- Workspace：本地工作区
- Project：按周或任务保存的分析项目
- SourceFile：原始文件元数据和只读引用
- Dataset：处理后的本地数据集
- FieldMapping：字段映射和别名
- JoinStep：每一步多表匹配关系
- RuleSet：异常或标题规则
- AnalysisView：透视、筛选和图表视图
- Diagnostic：策略诊断卡片
- TitleCandidate：标题候选和审核状态
- TrendNote：热点观察
- SupplierIssue：供应商问题
- Task：日常任务
- ReportDraft：报告草稿
- Template：可复用模板
- TutorialProgress：教程进度

### 17.2 历史项目

每周项目保存导入文件元数据、字段映射、匹配链路、规则、异常、人工标记、AI 建议、人工修改、报告和导出记录。

支持复制上周项目、对比项目、归档、备份和删除。历史对比缺少对应周期时必须明确提示，不能强行计算。

### 17.3 备份与恢复

支持导出工作区备份包，并选择：模板和规则、项目配置、分析结果、原始数据。

- 默认不包含 API Key。
- 导入前显示内容、版本和文件大小。
- 支持恢复单个项目或完整工作区。
- 冲突处理：跳过、覆盖、另存为副本。
- 删除进入本地回收站，建议保留 30 天。
- 清空全部数据需要强确认，并明确不可恢复。

## 18. 状态与错误恢复

- 原始数据只读。
- 清洗、匹配、规则和报告编辑保存处理步骤。
- 支持撤销、重做和回到指定步骤。
- 报告和标题编辑自动保存草稿。
- 批量确认、覆盖模板、删除项目需要二次确认。
- 历史版本恢复默认另存为副本。
- 导出前执行完整性检查。

错误提示必须告诉用户：发生了什么、影响什么、如何修复、是否可以跳过以及数据是否已保存。

## 19. 可追溯性要求

所有关键指标、图表和诊断都要支持查看：

- 来源文件和工作表
- 使用字段
- 匹配关系
- 过滤条件
- 统计周期
- 计算公式
- 异常阈值
- 规则版本
- 是否经过 AI 辅助
- 最后更新时间

示例：

```text
转化率 = 支付件数 / 点击量
来源：销售数据.xlsx / Sheet1 + 流量数据.xlsx / Sheet2
周期：2026-08-17 至 2026-08-23
过滤：站点=US，品类=女装
```

## 20. 视觉与交互规范

- 背景使用暖白或极浅粉，主色为低饱和樱花粉。
- 辅色可用淡紫、雾蓝、薄荷绿区分状态，但避免单一色系占满页面。
- 液态玻璃用于侧栏、顶部工具栏、弹窗和指标卡片。
- 数据表格、匹配结果和报告编辑区优先清晰，不使用高透明导致对比度不足。
- 成功、警告、异常分别使用绿色、橙色和红色。
- 中等圆角，避免页面堆叠大量装饰卡片。
- 动效只用于淡入、展开和状态反馈，支持减少动效。
- 主要操作使用清晰的图标和文字，图标按钮提供提示。
- 文字必须在桌面和窄窗口内完整显示，不依赖超小字号。
- 提供“专注工作模式”，降低透明度和装饰效果。

## 21. 响应式范围

- 1440×900：完整桌面体验
- 1280×800：常用办公体验
- 1024px：可用，侧栏或面板允许折叠
- 手机端：只读查看指标、待办、风险、报告和供应商状态
- 手机端不支持多表匹配、复杂透视、批量标题审核和报告自由编辑

## 22. 非功能要求

### 性能

- 小型文件导入后应快速显示预览和字段建议。
- 大文件处理显示进度、阶段和取消入口。
- 多表匹配避免阻塞页面，必要时使用分步处理。
- 单个任务 10 张表和 50MB 文件是首版建议上限，实际限制应可调整。

### 兼容性

- 支持当前版本 Chrome 和 Edge。
- 不要求安装 Excel；浏览器负责读取和导出文件。
- 导出的 XLSX、DOCX 和 PDF 应能在常见办公软件打开。

### 安全与隐私

- 本地优先，不默认联网。
- 不记录明文 API Key 到报告、日志和备份。
- AI 调用前必须明确目标接口和数据范围。
- 原始文件不被修改。
- 提供清空本地数据和回收站管理。

### 可访问性

- 关键流程支持键盘操作。
- 颜色不是唯一状态表达方式，同时使用文字和图标。
- 动态状态使用可读提示。
- 表格、图表和弹窗有明确标题和焦点顺序。

## 23. 首版验收标准

### 新手体验

- 第一次打开后 5 分钟内理解导航和首页。
- 15 分钟内用模拟数据完成一次完整分析。
- 30 分钟内能导入第一份真实表格并得到可解释结果。
- 不看开发文档也能完成“导入 → 匹配 → 分析 → 导出”。

### 数据分析

- 能导入 XLSX、XLS、CSV 和多个工作表。
- 能处理多于 3 张表的连续匹配。
- 每一步匹配都可确认、预览和查看异常。
- 缺失字段不会阻断整个文件，相关分析会明确关闭原因。
- 规则阈值可修改并保存。
- 异常结果包含证据和计算口径。
- 诊断卡片能记录人工确认的策略和跟进结果。

### AI

- 不配置 AI 时本地规则分析可完整运行。
- 配置兼容接口后可测试连接。
- 发送前能预览脱敏结果。
- AI 原因假设与事实证据有明确区分。
- AI 不会自动修改原始数据、标题或线上商品。

### 标题与报告

- 标题可批量生成多语言候选。
- 未审核标题不能导出。
- 报告模块可编辑、排序、隐藏并保存模板。
- 可导出 Excel、Markdown、HTML、Word 和 PDF。
- 报告包含周期、数据来源、规则版本和生成时间。

### 恢复与安全

- 原始文件保持不变。
- 关键操作支持撤销或版本恢复。
- 工作区可导出和恢复，API Key 默认排除。
- 删除项目有确认和回收站机制。
