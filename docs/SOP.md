# 海外商品运营工作台 SOP 教程

> 适用版本 v0.1+ · 本地优先 · 数据只存本机浏览器 · AI 仅作辅助假设需人工确认
> 本文档为唯一事实来源（docs/SOP.md），功能更新后同步更新此页。

## 一、首次准备（5 分钟）

1. 环境要求：Node.js ≥ 18，Chrome/Edge 桌面端。
2. 获取与启动：
   - git clone「仓库地址」后进入目录执行 npm install；
   - npm run dev 启动，浏览器打开 http://127.0.0.1:5174。
3. （可选）配置 AI 接口：「设置与数据管理」→ 填 OpenAI 兼容接口地址 / 模型 / API Key → 测试连接。不配置不影响本地分析。
4. 首次学习：进入「教程与帮助」→ 点「用示例数据开始练习」，按 6 步快速引导走完一次完整分析。

## 二、每周商品数据分析 SOP（核心流程）

### STEP 0 新建/复制项目
- 首页「新建分析项目」，或在「历史项目」复制上周项目（沿用映射与配置）。
- 项目字段：名称、周期、站点、品类范围。创建后导入副本与配置一起存本机，刷新可续做。

### STEP 1 导入数据
- 「商品数据分析」→ 导入 Excel/CSV（支持多文件多工作表；单表超 10 万行自动截断并提示）。
- 选择要检查的表：查看字段、示例值与质量摘要（行数/字段数/空值列）。
- 失败容错：单个文件解析失败只提示该文件及原因，其余文件照常导入。

### STEP 2 数据质量检查
- 关注「发现 N 个需要留意的问题」：空值列优先处理或备注原因。

### STEP 3 多表匹配
- 示例模式：演示 销售→商品→品类→供应商 连续匹配，关注未匹配数、重复键、行数膨胀。
- 真实导入：导入 ≥2 张表后出现匹配编辑器 → 选主表/关联表 → 关联键（系统推荐同名键，纯中文键请人工确认）→ 预览输出行数/未匹配/重复键后再进入分析。

### STEP 4 字段映射确认
- STEP 04 展示自动识别结果（含置信度）；下拉框可手动覆盖 商品ID/日期/曝光量/点击量/支付件数/销售额/品类，留空=使用自动识别。
- 缺必选列或同列重复映射会被拦截；低置信度推荐会提醒人工确认。

### STEP 5 分析与诊断
- 筛选栏：日期范围 + 品类，实时生效（显示当前行数与环比徽章）。
- 自定义规则（可选）：选指标 + 比较方式 + 阈值 → 添加规则，命中结果与默认规则并列展示。
- 异常卡片：每条可一键「转日常任务」「转供应商问题」，在对应模块继续跟进。
- AI 假设（可选）：点「AI 原因假设」→ 核对脱敏预览 → 手动「确认发送」。结果仅是假设，必须人工验证后才可写入报告结论。

### STEP 6 透视、漏斗与导出
- STEP 06 自动生成品类透视条形图 + 曝光→支付漏斗。
- 「导出 Excel」包含：异常商品 / 品类透视 / 漏斗汇总 / 匹配明细四个工作表。

### STEP 7 周报产出
- 「周报与报告」自动绑定当前项目（标题/周期/数据来源），诊断取项目真实分析摘要；无项目数据时显示示例并明确标注。
- 支持模块编辑、撤销/重做；草稿按项目自动保存，下次打开恢复。
- 导出前查看完整性检查提示（未确认 AI 假设 / 周期缺失 / 空模块），再选择 Markdown/HTML/Word/Excel/PDF 导出。

## 三、标题优化 SOP

1. 「标题优化」→ 设置目标语言与禁用词（支持中英文逗号、顿号分隔）。
2. 本地「重新生成」模板候选；需要 AI 时点「AI 候选」→ 脱敏预览 → 确认发送（结果标记 AI 辅助 + 待审核）。
3. 审核：逐条看校验结果（长度/禁用词/事实一致性）；粉色高亮词 = 相比原标题新增的词。
4. 批量审核：勾选多条 → 「通过所选 / 退回所选」。
5. 「导出已通过」仅导出已通过项（JSON）。

## 四、供应商问题 / 日常任务 / 热点 SOP

- 供应商问题：类型/优先级/截止日/自定义字段 → 状态流转 待确认→处理中→等待供应商→已解决→已关闭；侧栏角标实时显示未关闭数量。
- 日常任务：筛选/逾期标记/延期；来自异常诊断的任务标注所属项目；顶栏通知徽章显示逾期任务+问题总数。
- 热点与选品：手动记录关键词/来源链接/截图备注，状态 待验证→已验证→已转化→已归档，可关联品类与商品。

## 五、历史项目与备份 SOP

- 对比：勾选两个项目 → 表格逐项对比（周期/站点/进度/表数量等，变更高亮）。
- 删除：同时清理该项目报告草稿（有确认弹窗，不可恢复）。
- 备份：定期「导出备份」JSON（自动剥离 API Key）；换机「导入备份」，冲突项目另存副本。

## 六、常见问题

| 问题 | 处理 |
| --- | --- |
| CSV 首列表头异常 | 已自动剥离 UTF-8 BOM；仍异常请检查文件编码 |
| 刷新后数据还在吗 | 在。导入副本随项目保存在本机 localStorage |
| 报告显示示例数据 | 说明还没有带分析摘要的本地项目；先完成一次导入分析即可 |
| AI 调用失败 | 检查接口地址/模型/Key 与网络；本地分析不受影响 |
| 清空某项目全部数据 | 历史项目 → 删除（含草稿）；或浏览器清除站点数据 |
